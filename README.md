# call-of-juarez-bound-in-blood-gun-warrior
## Call of Juarez Bound in Blood - Gun Warrior Remake
A remake of *Gun Warrior* — rebuilt in the **Call of Juarez: Bound in Blood** engine (Chrome Engine), using its Western setting, weapon handling, and Chrome Engine technology as the technical base.
